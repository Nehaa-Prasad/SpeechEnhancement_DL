# 🎧 Speech Enhancement using Deep Learning (Autoencoder)

This project removes background noise from speech signals using a Denoising Autoencoder built with TensorFlow.

## 🧠 Features
- Automatically adds artificial noise to clean speech
- Trains a Deep Learning Autoencoder to denoise audio
- Saves enhanced speech output and visualizes waveforms
